# CISTAC 1.0: AI4Brain, Cognitive Growth Agent (brief, text version)

Text transcription of `docs/challenge-brief.pdf` (the official brief). If they ever differ, the PDF wins.

## 1. Scope
AI4Brain explores how generative AI, cognitive science and adaptive learning can support personalised cognitive development. Unlike traditional cognitive tests, it continuously assesses users and adapts coaching and learning activities to their evolving profiles.

## 2. Objective
Build a cognitive growth AI agent that can:
- **Assess:** profile the user across the cognitive dimensions "listed in Section 3", non-clinically. (The brief never actually lists them; the team uses memory, attention, speed, reasoning, flexibility. Confirm with the organisers.)
- **Understand:** turn performance and errors into an uncertainty-aware, percentage profile.
- **Coach:** give explainable, personalised feedback and motivation.
- **Improve:** generate adaptive exercises and measurable learning paths.

## 3. Technical instructions and deliverables
Layers A–C are mandatory; Layer D is optional.

- **A: Assessment & profiling.** Tasks per cognitive dimension; collect score, response time, error rate, behaviour. Each dimension documented (definition, tasks, scoring, uncertainty, biases). Camera/voice optional; a non-biometric mode is mandatory.
  - **Brain Twin:** dynamic, historised profile. Mandatory: history. Optional: future projections, always with uncertainty, never as certainty.
- **B: AI coach.** Explainable natural-language coaching; free but justified architecture; no clinical terms.
- **C: Adaptive learning & dashboard.** Difficulty and exercise adaptation, evolving plans, radar chart, progress curves, heatmaps, goal tracking.
- **AI Collaboration Score:** how effectively the user collaborates with the AI, 0–100, with a documented formula. Proposed weights: clarification 20%, critical verification 25%, iteration 20%, autonomy 20%, responsible use 15% (a design proposal, not validated).
- **Ethics & data:** consent, retention and deletion documented; no sensitive decision on face/voice alone.
- **Deliverables (same at every stage):** GitHub repo, 3–5 min demo video, technical report (max 8 pages), presentation (max 15 slides).

## 4. Bonus (optional, Layer D)
Voice-based coaching, emotion-aware AI, predictive cognitive growth.

## 5. Selection
- **Phase 1, preselection:** GitHub repo, demo video, presentation (≤15 slides). **Deadline: 1 Nov 2026.** Jury selects finalists.
- **Phase 2, pitch (7 Nov 2026):** 8 min presentation + 5 min questions, including a surprise element revealed one day before.

## 6. Evaluation
Each entry is scored by ≥2 evaluators.
- **Phase A:** relevance 20%, quality 20%, innovation 20%, UX 15%, explainability 15%, safety 10%.
- **Phase B:** generalisation 25%, robustness 25%, profile quality 20%, plan relevance 15%, defense 15%.
- **Overall:** Phase 1 60%, Phase 2 40%.

## 7. Rules
English is the official language for submissions, pitch and defense. Any external tools/libraries allowed. Repositories must be public at submission. Teams keep their IP.

## 8–9. Submission and team
Submit repo, video and slides via the committee's form before the Phase 1 deadline. Teams of 2–4 (+1 if an IEEE CIS member, +1 if an IEEE YP member).
